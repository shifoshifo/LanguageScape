# LanguageScape

LanguageScape is a RuneLite plugin designed to help players learn real-world languages while playing Old School RuneScape.

## Planned Features

- Learn vocabulary through items obtained during gameplay.
- Support for multiple languages, initially Spanish and Arabic.
- Transliteration support for non-Latin writing systems.
- Earn vocabulary XP, build streaks, and master words.
- Review previously encountered vocabulary.
- Future support for voice recognition and pronunciation practice.

## Development Status

LanguageScape is currently in early development.
